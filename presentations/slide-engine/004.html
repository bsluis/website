A homegrown CMS

Each slide is a fenced block in a single Markdown file. Slot fences map content to web component slots — no GUI, no database.

---
type: content-image
title: My Slide
notes: Speaker notes go here.
---

Why this works

  • One file, one source of truth
  • Plain text — version-controlled, diffable, grepable
  • Slots are explicit — no guessing where content lands
  • The pipeline validates every slide at build time and fails loudly on errors
  • Works in any editor, on any machine, forever
